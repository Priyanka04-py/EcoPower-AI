# EcoPower AI – Smart Electricity Usage Analyzer

EcoPower AI is a simple AI-based application that analyzes electricity consumption data, detects unusual usage patterns using machine learning, and provides simple energy-saving recommendations.

## Features

- Upload electricity consumption data in CSV format
- Detect unusual consumption using Isolation Forest
- Visualize electricity consumption
- Identify anomalous usage patterns
- Provide simple energy-saving recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly

## SDG Alignment

This project supports **SDG 7 – Affordable and Clean Energy** by encouraging efficient and responsible electricity consumption.
